✅ SPV 验证演示

轻节点如何仅通过区块头和少量数据验证交易？

场景：你是轻节点（SPV 钱包），只想验证 "Tx1: Alice->Bob" 是否包含在区块中， 而不想下载整个区块的所有交易。

📖 默克尔树特性

🎯 数据完整性

任何交易的修改都会导致默克尔根变化，从而被立即发现。

⚡ 高效验证

轻节点只需 O(log n) 的数据即可验证交易，而非下载全部交易。

🔒 安全性

哈希函数的不可逆性确保了无法伪造证明路径。

📦 节省空间

区块头只需 32 字节存储默克尔根，无论区块中有多少交易。

💡 为什么比特币需要默克尔树？
如果没有默克尔树，轻节点要验证一笔交易，必须下载整个区块的所有交易（可能几 MB 到几 GB）。 有了默克尔树，轻节点只需下载 80 字节的区块头 + 几百字节的证明路径！

import hashlib def double_sha256(data): """双 SHA256 哈希""" return hashlib.sha256(hashlib.sha256(data).digest()).digest() def calculate_merkle_root(tx_hashes): """ 计算默克尔根 tx_hashes: 交易哈希列表（字节串列表） """ if len(tx_hashes) == 0: return bytes(32) # 逐层计算 while len(tx_hashes) > 1: # 如果数量是奇数，复制最后一个 if len(tx_hashes) % 2 == 1: tx_hashes.append(tx_hashes[-1]) # 两两配对哈希 new_level = [] for i in range(0, len(tx_hashes), 2): combined = tx_hashes[i] + tx_hashes[i+1] new_level.append(double_sha256(combined)) tx_hashes = new_level return tx_hashes[0] # SPV 验证：验证交易是否在区块中 def verify_merkle_proof(tx_hash, merkle_root, proof_path): """ 验证默克尔证明 proof_path: [(sibling_hash, is_left), ...] """ current_hash = tx_hash for sibling_hash, is_left in proof_path: if is_left: # 兄弟节点在左边 current_hash = double_sha256(sibling_hash + current_hash) else: # 兄弟节点在右边 current_hash = double_sha256(current_hash + sibling_hash) return current_hash == merkle_root
