📖 挖矿原理

1

准备区块头

矿工将 Version、PrevHash、MerkleRoot、Timestamp、Bits 和 Nonce 组合成 80 字节的区块头。

2

计算哈希

对区块头进行双 SHA256 哈希计算，得到 256 位的哈希值。

3

验证难度

将哈希值与目标值比较。如果 hash < target，则找到有效区块！否则增加 Nonce 重试。

💡 真实情况：
当前比特币网络难度极高，专业 ASIC 矿机每秒可进行数十万亿次哈希计算。 这个模拟器使用大幅降低的难度，让你能在浏览器中体验挖矿过程。

💻 代码实现

import hashlib import struct import random class Miner: def __init__(self, block_header): self.block_header = block_header self.nonce = 0 def mine(self, target): """挖矿主循环""" while True: # 将 nonce 放入区块头 header_with_nonce = self.block_header + struct.pack(', self.nonce) # 计算双 SHA256 hash1 = hashlib.sha256(header_with_nonce).digest() block_hash = hashlib.sha256(hash1).digest() # 检查是否满足难度目标 if int.from_bytes(block_hash, 'big') < target: return { 'nonce': self.nonce, 'hash': block_hash[::-1].hex() } # 尝试下一个 nonce self.nonce += 1 # 如果所有 nonce 都试过，修改时间戳或其他字段 if self.nonce > 0xFFFFFFFF: raise Exception("所有 nonce 已尝试完毕") # 使用示例 miner = Miner(block_header_bytes) result = miner.mine(target_value) print(f"找到区块! Nonce: {result['nonce']}") print(f"区块哈希: {result['hash']}")
