⛰️ 难度目标 (Difficulty Target)

理解比特币的 Bits 字段和难度目标计算

🎯 难度目标可视化

区块哈希（作为大整数）必须 小于 目标值才有效。 目标值越小，挖矿难度越大。

0 (最容易) 目标值 2²⁵⁶-1 (最难)
当前目标值 (十六进制)
00000000ffff0000000000000000000000000000000000000000000000000000
简单 (大目标值) 中等难度 困难 (小目标值)
💡 挖矿规则：
hash(block_header) < target

目标值越小，满足条件的哈希就越少，找到有效 Nonce 所需的计算量就越大。

🔧 Bits 解析器

Bits 是难度目标的紧凑表示（4 字节），需要展开成 32 字节的目标值。

转换公式
Target = Coefficient × 256^(Exponent-3)
Bits 格式: [Coefficient: 3 bytes][Exponent: 1 byte]

📈 难度调整：
比特币每 2016 个区块（约 2 周）调整一次难度，使平均出块时间保持在 10 分钟左右。 如果算力增加，难度会相应提高。

💻 代码实现

Python

def bits_to_target(bits): """ 将 compact bits 转换为 256 位目标值 bits: 4 字节，格式为 [系数 3 字节][指数 1 字节] """ # 指数是最后一个字节 exponent = bits[-1] # 系数是前 3 字节（小端序） coefficient = int.from_bytes(bits[:3], 'little') # 计算目标值 target = coefficient * (256 ** (exponent - 3)) return target def target_to_bits(target): """将目标值转换回 compact bits""" # 转换为十六进制字符串 hex_str = format(target, '064x') # 找到第一个非零字节 hex_str = hex_str.lstrip('0') if len(hex_str) <= 6: hex_str = hex_str.zfill(6) # 提取系数和指数 coefficient = int(hex_str[:6], 16) exponent = (len(hex_str) + 1) // 2 # 打包成 bits return coefficient.to_bytes(3, 'little') + bytes([exponent]) # 验证 PoW def validate_pow(block_hash, target): """验证区块哈希是否满足难度目标""" hash_int = int.from_bytes(block_hash, 'big') return hash_int < target

JavaScript

function bitsToTarget(bits) { // bits 是 Uint8Array (4 bytes) const exponent = bits[3]; const coefficient = bits[0] + (bits[1] << 8) + (bits[2] << 16); // 使用 BigInt 计算大数 const target = BigInt(coefficient) * (BigInt(256) ** BigInt(exponent - 3)); return target; } function validatePoW(blockHash, target) { // blockHash 是 Uint8Array (32 bytes) const hashHex = Array.from(blockHash) .map(b => b.toString(16).padStart(2, '0')) .join(''); const hashInt = BigInt('0x' + hashHex); return hashInt < target; }
