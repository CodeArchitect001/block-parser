# 记忆 04: 关键概念速查

## 📦 区块头结构（80 字节）

```
字节范围    字段          类型       字节序
[0:4]      Version      uint32     小端序
[4:36]     PrevHash     [32]byte   原样存储
[36:68]    MerkleRoot   [32]byte   原样存储
[68:72]    Timestamp    uint32     小端序
[72:76]    Bits         [4]byte    紧凑格式
[76:80]    Nonce        uint32     小端序
```

---

## 🔄 字节序规则

### 黄金法则
| 场景 | 字节序 | 说明 |
|------|--------|------|
| **存储** | 小端序 | 比特币协议使用小端序 |
| **显示** | 大端序 | 人类阅读、区块浏览器 |
| **哈希输入** | 原样 | 保持原始字节序 |
| **哈希比较** | 大端序 | 翻转后转整数比较 |

### 快速对比
```
数值: 0x12345678 (305419896)

小端序存储: [78 56 34 12]  ← 低字节在前
大端序显示: [12 34 56 78]  ← 高字节在前
```

---

## 🔐 双 SHA256

```
数据 → SHA256 → 中间哈希 → SHA256 → 最终哈希(32字节)
```

### 计算流程
1. 第一次 `hash1 = SHA256(data)`
2. 第二次 `hash2 = SHA256(hash1)`
3. 结果 `hash2` 就是双 SHA256 结果

---

## ⛰️ 难度目标

### Bits 格式（4字节）
```
[系数 3字节(小端序)] [指数 1字节]

示例: 0x1d00ffff
- 系数: 0x00ffff = 65535 (小端序存储: ffff00)
- 指数: 0x1d = 29
```

### 计算公式
```
Target = Coefficient * 256^(Exponent - 3)
       = Coefficient * 2^(8 * (Exponent - 3))
```

### 创世区块目标值
```
0x00000000ffff0000000000000000000000000000000000000000000000000000
```

---

## ✅ PoW 验证规则

```
block_hash (作为大端序整数) < Target
```

### 验证步骤
1. 计算区块哈希（双 SHA256）
2. 将哈希字节 **翻转**（小端序→大端序）
3. 转换为大整数
4. 比较：哈希值 < 目标值
